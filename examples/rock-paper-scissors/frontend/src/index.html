Rock beats scissors, scissors beats paper, paper beats rock — pick Well mode when starting a table for a fourth symbol (paper and well each cover two of the others; rock and scissors each cover one). First to 3 round wins takes the match. Your Player ID is per browser tab — open a second tab to play the other seat — unless you log in with Internet Identity, which gives you the same Player ID everywhere, permanently. An idle game can be taken over after 60 seconds.
